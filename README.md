# Bid App — Silent Auction Mobile Application

A cross-platform mobile application built with **React Native** that enables users to participate in silent auctions in real time. Tested on both iOS and Android with real users.

---

## Features

- Browse active auction items with descriptions and images
- Place bids in real time with instant UI feedback
- View current highest bid and bidding history per item
- User-friendly interface designed for fast, intuitive interaction
- Cross-platform support — runs on both iOS and Android from a single codebase

---

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/) or React Native CLI
- iOS Simulator (Mac only) or Android Studio Emulator

### Installation

```bash
# Clone the repository
git clone https://github.com/Akbari86/bid-app.git

# Navigate into the project folder
cd bid-app

# Install dependencies
npm install

# Start the development server
npx expo start
```

### Running on Device

```bash
# Run on Android
npx expo start --android

# Run on iOS
npx expo start --ios

# Run in web browser
npx expo start --web
```
